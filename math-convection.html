The problem

0Given

T∞20 °C = 293.15 Kinlet air temperature

then  Tw,max,  Tout,  Q

The air

1Density

ρ = pR T

ρ = 101 325287.05 × 293.15 = 1.204 kg/m3

2Viscosity

μ = μ0 (TT0)3/2 T0 + 110.4T + 110.4

μ = 1.813×10−5 Pa·s,   ν = μρ = 1.506×10−5 m2/s

3Conductivity

k = k0 (TT0)3/2 T0 + 194T + 194

k = 0.02570 W/(m·K),   cp = 1006 J/(kg·K)

α = kρ cp = 0.025701.204 × 1006 = 2.121×10−5 m2/s

What kind of flow is this?

4Reynolds

ReL = U∞ Lν

ReL = 1.0 × 0.121.506×10−5 = 7969

≪ 5×105  ⇒  laminar ✓

5Prandtl

Pr = να = μ cpk

Pr = 0.710

heat spreads a little faster than momentum  ⇒  thermal layer slightly thicker

6Plate: one temperature through the thickness?

Bi = h tks

Bi = 11.6 × 0.003167 = 2.1×10−4

Bi ≪ 0.1  ⇒  Tw = Tw(x, t) only ✓

7Buoyancy

Ri = g β ΔT LU∞2,   β = 1T∞

Ri = 9.81 × 34.4 × 0.12293.15 × 1.02 = 0.14

just above 0.1: buoyancy is small but not zero. Not modeled.

Governing equations

8Mass

∂u∂x + ∂v∂y = 0

9Momentum

∂u∂t + u ∂u∂x + v ∂u∂y = −1ρ ∂p∂x + ν ( ∂2u∂x2 + ∂2u∂y2 )

∂v∂t + u ∂v∂x + v ∂v∂y = −1ρ ∂p∂y + ν ( ∂2v∂x2 + ∂2v∂y2 )

10Energy, air

∂T∂t + u ∂T∂x + v ∂T∂y = α ( ∂2T∂x2 + ∂2T∂y2 )

11Energy, plate

ρs cs t ∂Tw∂t = ks t ∂2Tw∂x2 + q″ − qw

qw = −k ∂T∂y |y=0

heater in, conduction along the plate, qw out to the air

12Boundaries

inletu = U∞,  v = 0,  T = T∞
plateu = v = 0,  T = Tw(x)no slip
floor, off the platev = 0,  ∂u/∂y = 0,  ∂T/∂y = 0free slip, insulated
top and outletp = 0,  ∂/∂n = 0open

A textbook estimate first

13Laminar plate, even heat flux

Nux = hx xk = 0.453 Rex1/2 Pr1/3

h̄ = q″mean(Tw − T∞) = 0.6795 ReL1/2 Pr1/3 kL

h̄ = 0.6795 × √7969 × 0.7101/3 × 0.025700.12 = 11.59 W/(m2·K)

mean Tw ≈ T∞ + q″h̄ = 20 + 40011.59 = 54.5 °C

14Heat and outlet air

Q = q″ L W,   Q = ṁ cp (Tout − T∞)

Q = 400 × 0.12 × 0.10 = 4.80 W

ṁ = ρ U∞ H W = 1.204 × 1.0 × 0.03 × 0.10 = 3.61×10−3 kg/s

Tout ≈ 20 + 4.803.61×10−3 × 1006 = 21.3 °C

15Will the aluminum stay even?

ks tL2  vs  h̄

167 × 0.0030.122 = 34.8 W/(m2·K)  >  11.6

the plate moves heat sideways 3× more easily than the air removes it

⇒ expect a nearly uniform Tw, not the textbook Tw ∝ x1/2

Solving it numerically

16Grid

100 × 48 cells,   Δx = 2.0 mm,  Δy = 0.625 mm

staggered: p, T at cell centres; u, v on cell faces

17Advection

φface = φU + ½ ψ(r) (φD − φU),   r = φU − φUUφD − φU

ψ(r) = r + |r|1 + |r|   (van Leer)

second order where smooth, never overshoots

18Projection

u* = un + Δt [ −(u·∇)u + ν∇2u ]

∇2p = ρΔt ∇·u*

un+1 = u* − Δtρ ∇p  ⇒  ∇·un+1 = 0

19Pressure, solved exactly

p(xi, yj) = Σk p̂k(xi) cos π (k + ½)(j + ½)Ny

p̂i−1 − 2p̂i + p̂i+1Δx2 − 2 − 2cos(π(k+½)/Ny)Δy2 p̂i = r̂i

max |∇·u| after each step ≈ 10−13 s−1

20Time step

Δt = min( 0.4|u|max/Δx + |v|max/Δy ,  0.42 max(ν, α)(1/Δx2 + 1/Δy2) )

Courant:  0.41.022/0.002 + 0.049/0.000625 = 0.678 ms

diffusion:  0.42 × 2.121×10−5 × 2.81×106 = 3.36 ms

Δt = 0.678 ms

21Plate, implicit

( CΔt + hc + 2κ ) Tw,in+1 − κ ( Tw,i−1n+1 + Tw,i+1n+1 ) = CΔt Tw,in + q″ + hc Ti,1n

C = ρs cs t,   κ = ks tΔx2,   hc = kΔy/2

C = 2700 × 896 × 0.003 = 7258 J/(m2·K)

τ = Ch̄ = 725811.6 = 625 s  (real aluminum)

the ÷1000 setting divides C only: τ = 0.62 s, same steady state
