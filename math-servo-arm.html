Why a diode

1Required duty

D = thighT

D = 1 … 2 ms20 ms = 5 … 10%

plain 555 astable:  thigh = 0.693 (R1 + R2) C > tlow = 0.693 R2 C  ⇒  D > 50% ✗

diode across R2: charge skips R2  ⇒  D < 50% ✓

The 555

2Thresholds

VL = Vcc3,   VH = 2Vcc3

VL = 2.00 V,   VH = 4.00 V

3Gap (discharge)

V(t) = VH e−t/R2C  ⇒  tlow = R2 C ln 2

tlow = 560×103 × 47×10−9 × 0.6931 = 18.24 ms

independent of Vcc and the pot

First try: a fixed diode drop

4Charge, Vd = 0.65 V

V(t) = V∞ − (V∞ − VL) e−t/RC,   V∞ = Vcc − Vd

thigh = R C ln V∞ − VLV∞ − VH

R = R1 + ½RV = 22 + 12.5 = 34.5 kΩ

thigh = 34.5×103 × 47×10−9 × ln 5.35 − 25.35 − 4 = 1.474 ms

5Check against SPICE

ngspice:  thigh = 1.348 ms

error = 1.474 − 1.3481.348 = +9.3%

5 V … 9 V, pot 0 … 100%: error +4.5% … +13.5% ✗

Fix: the diode equation

6How much current?

I ≈ Vcc − V − VdR

I ≈ 6 − 2 − 0.534 500 = 0.10 mA

7Shockley

Vd = n VT ln( IIs + 1 ) + I Rs

Vd = 1.752 × 0.025865 × ln 1.02×10−42.52×10−9 = 0.481 V   at V = VL

Vd = 0.444 V   at V = VH  (I = 0.045 mA)

0.44 – 0.48 V, not 0.65 V  ⇒  faster charge, shorter pulse

8Solve and integrate

I = Vcc − V − Vd(I)R   (Newton, each V)

thigh = ∫V_{L}VH C dVI(V)   (Simpson, 48 panels)

R = 34.5 kΩ:  thigh = 1.3495 ms

ngspice: 1.3484 ms  ⇒  error +0.08% ✓

Choose R₁

12Angle

pot range:  0.6° … 172.9°

13Servo speed

| dθdt | ≤ 500 °/s

0° → 180°:  180500 = 0.36 s

14Forward kinematics

φ = θ1 − 90°,  e1 = θ2,  e2 = θ2 + θ3 − 180°

r = l1 cos e1 + (l2 + l3) cos e2

x = r cos φ,  y = r sin φ,  z = h0 + l1 sin e1 + (l2 + l3) sin e2

home: θ = (90°, 100°, 80°),  h0 = 72,  l = (105, 100, 58) mm

r = 105 cos 100° + 158 cos 0° = 139.8 mm

z = 72 + 105 sin 100° + 0 = 175.4 mm  ⇒  tip (139.8, 0, 175.4) mm

15Gripper

α = θ4180° × 30°,   gap = 2 [ 7 + (l3 − 12) sin α ]

θ4 = 40°  ⇒  α = 6.7°,  gap = 2 (7 + 46 sin 6.7°) = 24.7 mm
